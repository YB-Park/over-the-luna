# Changelog

## 2.0.0-rc.1 — 2026-10-16

**Breaking, opt-in preview**, not a stable public release:
- Single host-governed Main; removes legacy Council, forced review and Premium UI.
- No model pins, custom tool permissions, API keys, MCP servers, hooks or auto escalation.
- Evidence-first code editing and risk-proportionate verification.
- Reproducible allowlisted local plugin ZIP, no-credit static CI and regression tests.
- Explicit coexistence with v1.1.1 and one-step rollback.

**Known limitation:** actual SDK execution was observed for the prior research package, but a unique quality/expense advantage over native Copilot and RC Host integration have not been proven.

Stable [v1.1.1](https://github.com/YB-Park/over-the-luna/releases/tag/v1.1.1) remains available unchanged on main.
